# Budget Tracker

## Project Description

This is a Budget Tracker website built using HTML and CSS. The project is an extension of the Budget Tracker created in Week 1.

The website allows users to view sample expenses and provides a form for entering new expenses. It also includes a budgeting video, a logo, and a collapsible section explaining how to use the tracker.

## Features

### 1. Expense Table

The project contains an HTML table with four columns:

* Name
* Amount
* Category
* Date

The table contains five sample expenses.

The table uses:

* `<table>`
* `<thead>`
* `<tbody>`
* `<tr>`
* `<th>`
* `<td>`

The CSS adds borders, padding, a colored header, alternating row colors, and a hover effect.

### 2. Add Expense Form

The form allows users to enter:

* Expense name
* Amount
* Category
* Date

The category uses a dropdown with five options:

* Food
* Transport
* Rent
* Entertainment
* Other

The form also contains an Add Expense button.

### 3. Multimedia

The page includes a Budget Tracker logo using an `<img>` element.

It also includes a YouTube budgeting video using an `<iframe>`.

### 4. Interactive Elements

The page includes a collapsible section using `<details>` and `<summary>`.

The table rows change appearance when the mouse moves over them.

The Add Expense button uses a pointer cursor.

### 5. CSS Selectors

The stylesheet uses advanced CSS selectors including:

* Descendant selector
* Direct child selector
* `:nth-child()` selector
* `:not()` selector
* `:focus` selector
* `:hover` selector

## Files

### index.html

Contains the structure and content of the Budget Tracker webpage.

### style.css

Contains the styling, table design, form styling, hover effects, focus effects, and advanced CSS selectors.

### README.md

Explains the project and describes the features and files.
