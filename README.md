# Budget Tracker

## Project Description

This is a Budget Tracker website built using HTML and CSS. The project was created in Week 1 and improved in Week 2 and Week 3.

The Budget Tracker allows users to view sample expenses and provides a form for entering expense information. In Week 3, the main focus was improving the visual identity and user interface using CSS.

The design was improved by adding a consistent color palette, custom Google Fonts, improved table and form styling, and the CSS Box Model.

## Week 3 Visual Design

### 1. Color Palette

A green-based color palette was selected to create a clean and professional budgeting interface.

The main colors include:

* Dark Green: `#1b5e20`
* Green: `#2e7d32`
* Light Green: `#e8f5e9`
* Background: `#f4f7f5`
* White: `#ffffff`
* Dark Text: `#333333`

These colors are used consistently across headings, buttons, table headers, table rows, cards, and the page background.

### 2. Typography

Google Fonts were used to improve the appearance and readability of the website.

Two fonts are used:

* **Poppins** for headings
* **Inter** for body text, labels, form inputs, buttons, and table content

This creates a clear visual hierarchy between headings and normal content.

### 3. Expense Table Styling

The expense table was improved using CSS.

The table includes:

* Green table header
* White header text
* Cell padding
* Borders
* Alternating row colors
* Hover effects
* Consistent typography

The alternating row colors make the expense information easier to read.

### 4. Add Expense Form Styling

The Add Expense form was improved with:

* Consistent font styling
* Spacing between labels and inputs
* Input padding
* Borders
* Rounded corners
* Focus effects
* Green Add Expense button
* Button hover effect

These changes make the form cleaner and easier to use.

### 5. CSS Box Model

The CSS Box Model was used throughout the project.

The main sections use:

* **Margin** to create space between sections.
* **Padding** to create space inside sections.
* **Borders** to define the cards.
* **Border-radius** to create rounded corners.

The following sections are displayed as separate visual cards:

* Page heading
* Add Expense form
* Expense table
* Budgeting video section
* Instructions section

### 6. Interactive Styling

Existing interactive elements were improved using CSS.

The project includes:

* Button hover effect
* Table row hover effect
* Input focus effect
* Pointer cursor on buttons
* Pointer cursor on the instructions section

## Files

Contains the structure and content of the Budget Tracker webpage, including the form, expense table, logo, video, and interactive section.

### `style.css`

Contains the visual styling for the Budget Tracker. It controls the colors, fonts, table, form, buttons, cards, spacing, borders, hover effects, and focus effects.
